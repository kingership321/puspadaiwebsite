# Admin and Moderation Specification

## Dashboard

Show:

- Total users
- Active listings
- Pending listings
- Published listings
- New inquiries
- Reports
- Recent activity

## Listing moderation

Admin can:

- View
- Approve
- Reject
- Pause
- Archive
- Edit
- Flag

Rejection should support an internal reason.

## User management

Admin can:

- View
- Suspend
- Restore
- Change permitted role
- Review activity

Sensitive operations require confirmation.

## Reports

Users can report:

- Incorrect information
- Fraud/scam concern
- Duplicate listing
- Inappropriate content
- Wrong location
- Property no longer available

## Audit trail

Record admin actions with:

- Actor
- Action
- Entity
- Timestamp
- Relevant metadata

## Admin UX

Optimize for safe operation, not visual novelty.

Destructive actions require confirmation.
