# SEO Specification

## Indexable pages

Prioritize:

- City pages
- Neighborhood pages
- Property detail pages
- Agency pages
- Agent pages
- Helpful guides
- Curated search landing pages where content is genuinely useful

## Metadata

Every indexable page needs:

- Unique title
- Meta description
- Canonical URL
- Open Graph metadata
- Twitter/X metadata where useful

## Property structured data

Where appropriate, use schema.org structured data for real-estate/property content. Validate output and avoid unsupported claims.

## Search pages

Do not index every arbitrary filter combination.

Use canonicalization and robots controls to avoid massive low-value URL permutations.

## Sitemap

Generate:

- sitemap index
- property sitemap
- location sitemap
- agency sitemap
- guide sitemap

## Internal linking

Link:

City → neighborhoods → properties

Agency → listings

Guide → relevant locations/properties

## Performance

SEO implementation must not compromise usability.

Images need:

- width/height
- lazy loading below fold
- responsive sizes
- descriptive alt text

## Duplicate content

Avoid duplicate pages caused by:

- Filter order
- Tracking parameters
- Multiple URL aliases
- Empty search parameters
