# Content and Copy Guidelines

## Voice

Use English that is:

- Clear
- Helpful
- Concise
- Trustworthy
- Internationally understandable

Avoid:

- Overly clever copy
- Unexplained real-estate jargon
- Fake urgency
- Misleading claims

## Buttons

Prefer explicit labels:

- Search properties
- View property
- Save property
- Contact agent
- Request a viewing
- Apply filters
- Clear filters

## Empty states

Be useful.

Example:

"No properties match these filters. Try increasing your price range or removing a filter."

## Error messages

Explain:

1. What happened
2. What the user can do

Never expose technical details.

## Listing descriptions

Preserve the provider's meaning but sanitize unsafe markup.

Do not generate fake property facts.
